# TradeMate

> **Historical project**
>
> This repository is preserved as a historical Electron/React trading-system experiment. Its dependencies and external integrations are obsolete, and current build or exchange compatibility is not claimed. Do not use it with production accounts or credentials. No profitability or trading-performance claim is made.

## Local configuration

Create React App loads local settings from an untracked `.env` file, not from `.env.example`. To recreate the documented local build settings:

```bash
cp .env.example .env
```

Keep the copied `.env` local and do not commit it. Do not add exchange or account credentials. Current build compatibility is not claimed.
